# ball-sim-image-revealer

Project designed for physically simulating balls which, when coloured, settle to form an image.

## Dependencies
### python
- tkinter (part of python install)
### C++
- SDL2 (included)
- ffmpeg (included)


## Notes
- venv is python virtual environment
- required C++ packages are contained under include folder
- no requirements.txt provided as tkinter is not provided by pip
